# Assignment 1 Practical Pack - Student Instructions

## What this pack contains
- `notebooks/Group_1_Starter.ipynb` ... `Group_5_Starter.ipynb`
- `resources/` - offline dataset, fixed validation set, and group-specific training manifests
- `weights/resnet18_source_pretrained.pth` - cached ResNet18 source-task checkpoint
- `utils/assignment_utils.py` - supplied training/evaluation/evidence utilities
- `assignment_docs/` - the formal assignment handouts

## Important: the dataset is a teaching dataset
The images are procedurally generated for this supervised assessment. They are designed to expose concepts such as class confusion, illumination shift, class imbalance, small-data overfitting, and data-quality problems. They are **not** evidence of real-world waste-classification performance.

Target classes:
- plastic (bottle/cup subtypes)
- paper (sheet/carton subtypes)
- metal (can/cap subtypes)

The validation set is fixed for all groups and contains stronger illumination variation than the common training set.

## Transfer learning in this pack
The cached ResNet18 was pretrained offline on a separate six-class source task:
`bottle`, `cup`, `sheet`, `carton`, `can`, `cap`.

The target task merges those source subtypes into three material classes. This means the transfer-learning section is genuine: the backbone begins with representations learned on a related source task rather than random initialization.

- change additional major variables during the controlled experiment;
